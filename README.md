 # ATM Machine Simulation in C

A simple console-based ATM simulator written in C that demonstrates basic banking operations using conditional statements (`if`, `else if`, `else`).

## Features
* **Withdraw Cash:** Deducts the requested amount from the initial balance (`10,000`) after checking for sufficient funds.
* **Deposit Cash:** Adds the deposited amount to the current balance and displays the updated total.
* **Balance Check:** Displays the current available balance.

## How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/lakshayraghav2607/ATM-MACHINE-.git
   cd ATM-MACHINE-
   ```

2. **Compile the code:**
   ```bash
   gcc atm.c -o atm
   ```

3. **Run the executable:**
   ```bash
   ./atm
   ```
